# Changelog

## v0.1.1 - 2026-08-22

- Renamed the project to `RenderCV Studio`.
- Added the `rendercv-studio` repository publishing instructions.

## v0.1.0 - 2026-08-22

- Added official RenderCV ClassicTheme-style Chinese one-page and two-page examples.
- Added `tools/yaml_studio.py`, a localhost web editor with CodeMirror YAML editing and real RenderCV PDF/PNG preview.
- Added save, browser draft recovery, YAML download, PDF download, automatic rendering, and validation error display.
- Added Linux/macOS and Windows launch scripts.
- Added GitHub Actions rendering workflow and anonymized placeholder assets.
